"RESTARTING! I am still making a game, but here is a completely new prompt for you to go off of:

I want to build a browser-based real-time strategy game called “Bushfire Balance” using only HTML, CSS, and JavaScript (with Canvas or a lightweight 2D library like Phaser.js if needed). It should resemble a Plants vs Zombies–style game where a house is on the left side of the screen, and fire advances from the right.

Core gameplay requirements:
- The player earns money over time as "income from a job." This ticks up each second. However, once the fire crosses a certain threshold (too close to the house), income stops.
- The playfield is a grid, similar to Plants vs Zombies. Defenses can be placed into tiles.
- Defenses include:
  - Water Hose: slows down fire in a lane.
  - Fire Block: temporary wall that absorbs fire.
  - Sprinkler: slows fire across multiple adjacent tiles.
- The fire starts as small embers or single flames in lanes, which can be put out. Fire can spread forward and sideways to adjacent tiles. Over time, waves of fire grow stronger and more unstoppable.
- The player has the option to "Leave" at any time before the fire reaches the driveway (located in the middle bottom of the grid). This is represented by a car sprite driving off-screen. Once the fire reaches the driveway, leaving is no longer possible.
- If the player leaves, the game ends with a financial report:
  - Money saved (unspent).
  - Expenses (house/property damage, which is always significant).
  - Outcome: survival guaranteed.
- If the player stays until the fire overwhelms the house, a cutscene triggers: the player hides inside. A random dice roll decides if they perish or survive. If they survive, the house is usually badly damaged. This highlights the "gamble" of staying.
- Important: It should be mechanically possible to delay the fire with defenses, but defeating the fire entirely is impossible. The waves always become overwhelming eventually.

UI requirements:
- Menu screen with title and "Start Game."
- Main play screen with:
  - Grid of tiles (for defense placement).
  - House sprite on the left.
  - Fire advancing from the right.
  - Money counter at the top.
  - Buttons for purchasing/placing defenses.
  - “Leave Now” button at the bottom center (disabled once fire reaches driveway).
- End screen with survival outcome, financial report, and restart button.

Tone and style:
- Serious overall tone, but sprites can be simple or slightly cartoony for clarity.
- Background should show a bushfire-prone environment (dry grass, smoky sky).
- Sound effects: optional but would add impact (crackling fire, alarm when leaving option is about to close).

Code requirements:
- Structure the project cleanly as:
  - index.html
  - style.css
  - script.js (or Phaser scenes if using Phaser)
- Keep code modular, with clear functions for:
  - Grid and placement logic
  - Fire spread logic
  - Income tick system
  - Leaving mechanic and end screen
  - Random survival dice roll on house cutscene
- Use placeholder sprites and simple assets first. I will replace them later.
- Comment the code clearly so I can expand with new defenses, more fire behaviors, or different endings.

Deliverable:
Please scaffold a first working prototype with:
- Menu → Play → End screen flow
- Basic grid with at least 3 defenses
- Fire that spreads and grows stronger
- Money income that stops once fire crosses a threshold
